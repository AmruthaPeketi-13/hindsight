# Hindsight — AI Operations Manager

## About
Hindsight is an AI-powered operations management platform that helps engineering teams troubleshoot technical issues by learning from past incidents. It uses semantic memory to retrieve relevant historical information and adaptive AI model routing to provide contextual responses while optimizing AI usage and costs.

## Features
- **AI Chat:** Get real-time responses to technical queries.
- **Semantic Memory:** Retrieve relevant information from past incidents.
- **Memory Vault:** Search, filter, and manage stored incidents.
- **Adaptive Model Routing:** Select AI models based on query complexity.
- **Analytics Dashboard:** Monitor AI usage, response times, and costs.
- **Real-Time Streaming:** Receive AI responses as they are generated.

## Tech Stack
- **Frontend:** React.js, Vite, Tailwind CSS
- **Backend:** Node.js, Express.js
- **AI Models:** Google Gemini API
- **Database:** SQLite, Supabase, pgvector
- **Communication:** Server-Sent Events (SSE)
- **Other Tools:** Prisma, Three.js
